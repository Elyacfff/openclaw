# 超级手机网站

> 🚀 一个集成了 20+ 模式、1000+ 功能的超级手机网站

## 特性

- ✨ **玻璃拟态设计** - 采用苹果风格的毛玻璃效果
- 📱 **移动端优先** - 专为手机浏览器优化
- 🎨 **20+ 模式** - 每个模式都是独立的功能模块
- 🛠️ **1000+ 功能** - 所有功能都可以正常使用
- ⚡ **流畅动画** - 精心设计的交互动画
- 🌙 **深色模式** - 支持深色/浅色主题切换

## 技术栈

- **框架**: Lit (Web Components)
- **构建工具**: Vite
- **样式**: CSS Variables + 玻璃拟态设计系统
- **路由**: Hash 路由 (SPA)

## 开始使用

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5174 查看网站

### 构建生产版本

```bash
npm run build
```

构建产物将在 `dist` 目录

### 预览生产版本

```bash
npm run preview
```

## 设计系统

### 玻璃拟态

网站采用玻璃拟态（Glassmorphism）设计风格，具有以下特点：

- 半透明背景
- 毛玻璃效果（backdrop-filter: blur）
- 柔和的边框和阴影
- 流动的渐变背景

### 颜色系统

- **Primary**: #007AFF (科技蓝)
- **Secondary**: #5856D6 (优雅紫)
- **Accent**: #FF9500 (活力橙)
- **Success**: #34C759 (成功绿)
- **Warning**: #FF9500 (警告橙)
- **Danger**: #FF3B30 (危险红)
